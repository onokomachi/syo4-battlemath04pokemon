# ぼうけんモード「ナンバーランド」— 設計メモ

小4算数の全14単元・151サブトピックを、3Dフィールドを歩いて集める
モンスター図鑑として遊べるようにしたモード。

以下は「なぜそうしたか」の記録なので、あとから作りかえるときの判断材料に使ってほしい。

---

## 1. いちばん大事な決めごと

### 151サブトピック = 151体のモンスター

`constants.ts` の `MATH_CATEGORIES` を学習順に走査して図鑑番号を振っているだけなので、
**問題データを足せば図鑑も自動で増える**。モンスターの名前・見た目・説明は
`data/adventure/monsterRoster.ts` にサブトピック名をキーとして書いてある。
ロスターに無いサブトピックが現れても落ちず、自動生成の名前で埋まる。

これにより「図鑑を完成させる = 小4算数をひととおり解く」が構造的に成立する。
ゲームの目標と学習の目標が別々にならないようにするための、いちばん重要な設計。

### 学習まわりは1行も作り直していない

問題データ・採点(`utils/answerChecker.ts`)・ガイド付き解答UI(筆算シミュレーター等)・
間隔反復(SRS)・学習記録・弱点分析は、練習モードとまったく同じものを呼んでいる。

そのために `ProblemScreen.tsx` にインラインで書かれていた問題ビューを
`components/ProblemQuestionView.tsx` に切り出した。**練習モードと3Dバトルが
同じコンポーネントを使う**ので、「モードによって同じ問題の答え方が違う」ことが
起こらない。

## 2. タイプ相性は「7すくみ」だけ

```
かず ▶ けいさん ▶ しょうすう ▶ ぶんすう ▶ ばい ▶ グラフ ▶ ずけい ▶ (かずへ戻る)
```

矢印の向きが「こうかは ばつぐん(×2)」、逆向きが「いまひとつ(×0.5)」、
それ以外はすべて等倍。**覚えるのは輪の順番ひとつだけ**にしてある。

18タイプ×18タイプの表を小4に覚えさせるのは学習の妨げになるだけなので採らなかった。
14単元を7タイプにまとめた対応は `data/adventure/elements.ts` の `ELEMENTS[].units`。

相性を外しても勝てる(×0.5で終わり、無効はない)ようにしてあるので、
「相性を考えると気持ちいい」が「相性を外すと詰む」にはならない。

## 3. まちがえたときの設計

学習アプリとして、ここがいちばん時間をかけた部分。

| できごと | 起きること |
|---|---|
| 1回目にまちがえる | 自分が少しダメージを受ける。**ヒントが出て、もう一度同じ問題に挑戦できる** |
| やり直しで正解 | ダメージは半分入る(直せたことを評価する) |
| 2回目もまちがえる | 正解が表示される。次の問題へ |
| まちがえた問題 | 自動で復習モード(SRS)に登録される |
| HPが0になる | かいふく所に戻るだけ。持ち物もモンスターも失わない |

「1回まちがえたら終わり」にしないこと、「負けても失うものがない」ことを徹底している。
既存アプリが持っている丁寧な解説・ヒント資産を、バトル中にそのまま活かせる形にした。

バトルの長さは、野生3〜5問 / トレーナー戦は相手1体につき3問 / 単元マスター戦は
相手1体につき4問(3体)。野生1回が1〜2分で終わるので、集中が切れにくい。

## 4. 3Dの作り方

**3D空間 + 2Dビルボードスプライト**。ポケモンのDS/3DS作品と同じ手法。

- 地形・草むら・木・岩・水面・空・霧・ライティングは本物の3D(three.js)
- キャラクターとモンスターは、生成した2Dイラストをつねにカメラを向く板に貼る

無料で用意できるのは高品質な2Dイラストであって3Dモデルではない。
プリミティブを組んだ簡易3Dモデルにすると、かえって安っぽく見える。
この構成なら**絵の品質がそのまま画面の品質になる**。

### フィールドは町IDから決定的に生成する

地形の高さ・木や岩の配置・草むらの位置は、すべて町IDのハッシュを種にした
疑似乱数から作る(`components/adventure/field/terrain.ts`)。

- 端末が変わっても、再訪しても、フィールドが変わらない
- 座標をセーブしなくてよい
- 地形の高さをどこからでも同じ式で引ける(NPCを地面に立たせるのが楽)

### 軽さのための選択

- 実影は使わず、まるいブロブシャドウで表現(モバイルGPUの負荷が大きく違う)
- 同じ形の飾りはすべて `InstancedMesh` 1つにまとめる
- three.js を含むチャンクは動的インポート。練習モードしか使わない児童の
  初期読み込みを遅くしない(本体936KB / ぼうけん1,005KB に分割ずみ)
- フィールドの外側に大きな地面と遠景の丘を置き、「板の上を歩いている」ように
  見えないようにしている

## 5. 操作(iPad横持ち・小4想定)

- **左下のバーチャルパッド**: 押した場所が中心になる方式。パッドの真ん中を
  正確に押さなくても動かせる
- **画面タップ移動**: 行きたい場所をタップすると歩いていく。ゲームに慣れていない子が
  最初の一歩でつまずかないための保険
- **右下の大きな丸ボタン**: 近くにNPCがいるときだけ光り、話しかけられる
- バトル中の問題画面は、iPadを横に持つと**左に問題・右にキーパッド**の2カラムになる

## 6. 進行

- 14の町は**どこから回ってもよい**。教科書の進度に合わせたい場合は、先生が
  管理画面の「単元ロック」で閉じる(既存機能をそのまま流用)
- ロックされた町はマップで 🔒 表示になり、入れない
- 14個のバッジがそろうと**ナンバーリーグ**が開く。四天王4人 → チャンピオン。
  途中で負けたら最初から(ただし失うものはない)

## 7. セーブとFirebase

`store/adventureStore.ts`。

- 平常時は **localStorage のみ**。Firebase未設定でも全機能が動く
- Firebase を設定してログインしている場合だけ、町の移動時とバトル終了後に
  `adventures/{uid}` へ `setDoc(merge)` を1回
- 端末をまたぐときは `updatedAt` が新しい方を採用するので、進行が巻きもどらない

フィールドを歩くたびに書き込むようなことはしていない(無料枠を使い切らないため)。

## 8. イラストの作り方

`scripts/` に生成パイプラインがある。詳しい手順は README を参照。

- **Pollinations.ai**(無料・APIキー不要)で1枚ずつ生成
- 背景は**必ずクロマグリーン**を指定させ、その色からの塗りつぶしで抜く
- 背景が緑でなければ「モデルが指示を無視した」と判断して**生成し直す**

最後の点は重要で、参照リポジトリ battlemath04catwars では背景を白にしていたため、
白い体のキャラが背景ごと溶ける不具合が起きていた。本作は
「背景色を検証してから抜く」ことでこれを構造的に防いでいる。
`scripts/check-sprites.mjs` が 200枚以上を機械的に検査して、抜け残り・抜きすぎを拾う。

### 画風

難易度が上がるほど、かわいい方から かっこいい方へ寄せている。

| 難易度 | グレード | 見た目 |
|---|---|---|
| 1〜2 | `baby` | まるっこくてやわらかい、パステル。武器も装備もなし |
| 3 | `brave` | 小さなマフラーやマントを着けた、元気な冒険者風 |
| 4 | `knight` | 簡素な鎧とマント。かっこいいが、こわくはしない |
| 5・ボス | `dragon` | まるい翼と短いしっぽを持つ、ちびドラゴン |

全生成で共通のスタイル文(フラットな2Dベクター / サンリオ風 / 大きな丸い目 /
グラデーション・毛並み・写実の排除)を共有して、画風のブレを抑えている。
グロテスクな表現・写実的すぎる描写は、ネガティブプロンプトで明示的に除外している。

## 9. ファイルの置き場所

```
data/adventure/
  elements.ts        7タイプと相性(7すくみ)
  adventureTypes.ts  型定義・とくせい・アイテム
  monsterRoster.ts   151体の名前・モチーフ・図鑑説明(サブトピック名がキー)
  monsters.ts        図鑑の組み立て(MATH_CATEGORIES と difficultyMap から決定的に)
  biomes.ts          14バイオームの色・光・霧・置くもの
  towns.ts           14の町(NPC配置・全セリフ・出現テーブル)
  people.ts          主人公・博士・ライバル・四天王・チャンピオン

components/adventure/
  AdventureMode.tsx  画面のきりかえとイベント進行
  BattleScreen.tsx   バトル(問題・ゲット・とくせい・タイプ相性)
  TitleScreen.tsx    なまえ・すがた・さいしょのなかま
  MenuScreens.tsx    図鑑・てもち・マップ・ショップ
  field/             3Dフィールド(地形・飾り・ビルボード・カメラ・エンカウント)
  ui/                バーチャルパッド・会話ウィンドウ

store/adventureStore.ts   セーブ(localStorage + Firebase任意同期)
scripts/                  スプライト生成・検査
```
