# ぼうけんのバトル・モンスターの育ち方・ごほうび・アイテム・ガチャ

## ぼうけんのバトル

- **ぼうけんのバトルは、必ず `AdventureMode` の `startBattle` を通す**（スタミナの関門）。`setBattle({...})` を直接呼ばない。
- **敵のレベルは 手持ち・バッジで上がる**（2026-11-12 先生と決めた「強め」。`store/adventureStore.ts` の `scaledOpponentLevel`）：手持ちの平均レベルが町の基準より高いと その差の9割まで追いつき、さらにバッジ1こにつき +1（60まで）。
  `startBattle` が すべてのバトル（野生・トレーナー・マスター・テキトウ団・四天王・チャンピオン）に かける。伝説・幻は そのまま。
- **伝説・幻（敵）は いつも一段えらい**（2026-11-12 先生と決めた。`legendOpponentLevel`）：決めてあるレベルと「手持ちの平均＋10」の高い方（65まで）。バッジに関係なく、伝説戦は いつも制限時間＋こうげき（ふつうの2倍）。
  祠の伝説は 勝つと そのレベルのまま仲間になる。野生の伝説は HP半分で「みとめられた」で終わり、3回みとめられると祠が開く（`shrineState` の `wildLegendRecognized`。前から）。
  **仲間にした伝説・幻は、担当の単元（`legend.units`）の正解で 半分ずつ育つ**（`growBySubtopic` の `LEGEND_GROWTH_RATE`。前は分野が無く 育たなかった）。
- **アビリティ（個体ごと。2026-11-12 先生と決めた。同じ日に「種類＋Lv1〜5＋複数もち」に作りなおした。`data/adventure/abilities.ts`）**：
  11種類（どれも同じ出やすさ）。1つ1つに Lv1〜5（効き目の表は `ABILITIES.values`。6つは そのまま・5つは 2倍）。数は なし55％・1つ40％・2つ4.5％・3つ0.5％、Lv は（それぞれ）55・28・12・4.5・0.5％（きびしめ）。
  `OwnedMonster.powers`（`{id, lv}[]`）。`powerVer` が `POWER_VER`(2) でない子は 読みこみ時に1回だけ きめなおす。色ちがい「✦ひかりのこ」（`shiny`）は アビリティとは別・1000体に1体・光るだけ。
  種類ごとの「とくせい」（`MonsterDef.ability`）とは別。効くのは ぼうけんのバトル（`BattleScreen` の `pv()`）と さいだいHP（`monsterMaxHp`）・けいけんち（`addExp`）。モンスター対戦・クラス対戦には効かない。
  表示は「⏳ ときのまもり Lv3（せいげん時間 ×1.3）」、箱は「⏳Lv3」。「にがす」（てもちの画面。`releaseMonster`）で MP（Lv・数・色ちがいで多い。`releaseMp`）。さいごの1体・伝説・幻は にがせない。図鑑の「つかまえた」は のこる。
- **アイテムの値段は 2026-11-12 に 約3倍**（ボール100・スーパーボール300・げんきドリンク150・げんきのかけら400・しおり150）。かいふく所（町）は ただのまま。
- **ジムに挑む条件は バッジ1こごとに 1割ずつ きびしく**（つかまえる数・正解数。`gymRequirements.ts` の `GYM_STEP_PER_BADGE`。その町のバッジは数えない）。
- **セーブの巻きもどり（2026-11-12 バグ直し）**：iPad の Chrome とホーム画面では セーブの置き場所が別。開いたまま別の方で遊んでから もどると 古いセーブでサーバを上書きしていた（「レベルが前にもどる」）。
  画面に もどったとき `pullSaveIfNewer` で サーバの方が新しければ読みなおす。見ているあいだは `pushSave` しない（`services/portal.ts` の `checkingRemote`）。
- **トレーナー戦などではボールを投げられない**（`catchable: false`。投げられるのは野生だけ）。トレーナーの手持ちと同じ種類は草むらにも出る（図鑑を ぜんぶ うめられるように。2026-11-12 先生と確かめた）。
- **ジムリーダー（マスター）に勝った町では、ボスモンスターも草むらに出る**（10回に1回。`AdventureMode` の `BOSS_WILD_RATE`。レベルは マスター戦のボスと同じ基準＋上の引き上げ。2026-11-12）。
- **制限時間**（2026-11-12 先生と決めた。`data/adventure/battleTimer.ts`、画面は `BattleScreen`）：バッジ7こから、すべてのバトル（野生もふくむ）で 問題ごとに制限時間。むずかしさ1→15秒 … 5→35秒、筆算シミュレーターなど操作の多い問題は3倍。
  超えると 3秒ごとに 相手の こうげき（いま出ている子の 最大HPの4％）＋「こうげきされた」演出（相手がとびかかる・画面のゆれ・赤い光・「〜の こうげき！」。CSS は `index.html` の `adv-*`）。
  答えを見ているあいだ・こうさんの確認中は止まる。演出で問題の画面を作り直さない（筆算の とちゅうの入力が消えるため）。開発ビルドでは `__advBadges(n)`・`__advEncounter()` で確かめられる。
- **トレーナー・伝説などのバトルは、どちらかが たおれるまで続く**（2026-11-11 先生と決めた。`BattleScreen` の `keepsGoing`・`addMoreProblems`）：問題を使いきったら同じ分野の問題を足す。前は「1体につき 3〜6問＋3」で打ち切って「きょうは ここまで」になり、伝説は正解が9〜25回いるのに8〜9問しか無く、全問正解でも勝てなかった。野生（にげる）・野生の伝説（HPを半分けずって みとめられる）は前のまま。

## モンスターの育ち方（2026-10〜 先生と決めた）

- **けいけんちは、正解した問題の「出どころのモンスター」にだけ入る**（`data/adventure/growth.ts` と store の `growBySubtopic`）。ぼうけんで野生のAと戦えば問題はAの分野なので、手持ちのAが育つ。ほかの手持ちには入らない（2026-10-24 先生と決めた。前は2割）。
  単元アプリの正解では けいけんちは入らない（上限＝かけら だけが上がる）。
  れんしゅう・ふくしゅう・対戦・テストの正解でも、その問題のモンスターが育つ（App の `setProblemLogHook`）。1日に満額は同じモンスターで20問まで、そのあとは4分の1。まちがえても減らない。
- **レベルの上限は単元の「かけら」で上がる**（kit の `sanmonShards`：単元アプリのテスト8割の日・実力の階段、アプリが無い単元は SANMON の練習）。上限 = 20 + 5×かけら（60まで）。
  上限では けいけんちを次のレベルの手前までためる。学級ポータルで名乗っていない（おためし）ときは上限なし。今までに上がったレベルは下げない。
- 強さ（`monsters.ts` の baseHp・baseAtk）は難しい単元ほど少しだけ強い（1.5倍ほど）。おもにレベルで決まる。
- **苦手ボーナス**（`growth.ts` の `WEAK_BONUS` ＝1.5）：きのうまでに まちがえて ふくしゅうリストに入った項目（`isWeakSubtopic`）を正解すると、
  けいけんち（れんしゅう・ふくしゅう・対戦・テスト・ぼうけん）と MP（ぼうけんで たおしたとき・れんしゅうの結果）が1.5倍。
  きょう まちがえたばかりの項目は数えない（わざと まちがえてから正解する、を防ぐ）。れんしゅうは はじめた時点で判定する。
- **レベルの上がり方（`monsters.ts` の `expToNext`）：Lv20 までは そのまま、Lv20→21 からは必要な けいけんちが3倍**（やりこみ。2026-10-24）。
  目安（その分野の正解）：Lv5→20 約135問・Lv20→40 約1,240問・Lv40→60 約2,040問。

## バトルのごほうび・アイテム・ガチャ（2026-10-24〜）

- **けいけんちとMPは「正解したこと」にだけ出す。** 問題を使いきっても勝ちにしない（相手がにげる＝`escape`）。
  正解したぶんは、にげても・負けても・使いきっても入る（`BattleScreen` の `growPendingCorrects`）。正解0問なら0。
  以前は使いきると勝ち扱い＋正解0でも1問ぶん足していたので、「わからない」連打で野生・トレーナー戦に勝てた。
- 自分の子がたおれて交代したら、その問題の状態（`showAnswer` など）を全部リセットして次の問題へ（そのままだと入力できなくなる）。
- アイテムは `data/adventure/adventureTypes.ts` の `ITEMS`。バトルでは「ボール」「どうぐ」のボタンから選ぶ。
  ヒントのしおり・ふくしゅうのおまもり・まぜこぜの巻物は、ふくしゅうモード・ミックスれんしゅうの正解でもらう（1日の上限あり）。
- **ガチャ（サンスウカプセル）のきまりは `data/adventure/gacha.ts`。ぼうけんの ショップ（`ShopScreen`）の中からだけ回せる。**
  コインは学習の成果（その日はじめての正解・はじめての熟達・はじめてのバッジ）だけ。MPは1回300で1日3回まで。
  確率はすべて画面に出す・10回で天井・シールを集めきってもごほうびなし（コンプガチャにしない）・お金では回せない。
  中身を変えたら、重みの合計を100のままにする（画面の％がそのまま重み）。道具60％・シール40％。
- **シール＝図鑑のモンスター全部**（ふつう・進化した すがた・単元ボス・伝説/幻）。めずらしいほど出にくい（30％・7％・2％・1％）。
  シール帳では 絵と「生態」（図鑑の説明）だけが見られる。シールでモンスターは手に入らない。前の形のシール（⭐など）は、同じ枚数のふつうのシールにかえた（`migrateOldStickers`）。
- メインメニューの「アイテム」から、効き目のなかった商品（ストリークシールド・テーマ・ヒントトークン）は外した。買っていた子には1回だけMPを返す。
